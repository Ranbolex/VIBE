# Before Publishing

- Upload only this directory to a new repository created with a neutral account.
- Do not use a personal commit name/email, fork, or link to a personal profile.
- Keep the inherited MIT notice intact; check the venue policy if its required
  upstream attribution could compromise review anonymity.
- Review the hosted repository, commit metadata, issues, actions, and profile
  links before putting an anonymized link in a manuscript.
- Do not describe this core package as a runnable SMAC training reproduction.

This directory has no inherited Git history, remote, credentials, results, or
checkpoints. Hosting choices cannot be audited until you upload it.
